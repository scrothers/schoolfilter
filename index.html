School Filter Check

Checks whether this device can reach sites in categories a school filter should block. Nothing is displayed from those sites; the page only probes whether a connection works. Everything runs in this browser.

Filter DNS

How it works

Each site goes through these steps, stopping as soon as there's an answer:

  1. 1.1.1.1: asks Cloudflare's DNS-over-HTTPS service whether the domain exists. If not, the site is GONE and nothing else is tried. If every row fails here, something is blocking 1.1.1.1 itself.
  2. Filter DNS (optional): asks the filtering DNS service you picked above. If it says the domain doesn't exist (NXDOMAIN or no answer), or answers with an internal address (10/8, 172.16/12, 192.168/16, 100.64/10, 127/8, 0.0.0.0, 169.254/16), that's a DNS BLOCK and the site isn't contacted. A public address that 1.1.1.1 disagrees with and that several unrelated sites share is that service's block page, and also counts as a DNS block.
  3. Connect: a GET https://domain/ from this browser. Fails on DNS blocks, connection resets, and certificate errors from block servers.
  4. Images: loads the site's own logo and icon images listed in baseline.json (up to 5, all served from that domain) and checks each comes back at the size recorded in the baseline. A filter's block page returns HTML, or the filter's own icon at some other size, so these fail even when the filter answers with 200 OK over intercepted HTTPS. Images also run when Connect fails, because Chrome reports some sites' bot-protection pages as a network error even though the site answered.

Baseline. baseline.json is made by gen-baseline.mjs on an unfiltered network: it finds each site's logo/icon images, keeps the ones that load in a real browser, and records their sizes. Results: ALLOWED means at least half of the site's images came back at the right size; SUSPECT means something answered but not the real images (a block page); BLOCKED means nothing got through; UNTESTABLE means it failed in the baseline too. Sites the generator found no image for (or only a single 16/32px favicon, which a filter's own icon could match) can only be checked for reachability, so an intercepted block page there looks allowed; the count is shown at the top. Without a baseline, the page falls back to /favicon.ico.

Filter DNS only shows what that service would answer; it can't confirm this device actually uses it. A browser can't see the device's own DNS answers at all, so on other setups a DNS block simply shows up as BLOCKED. Filter services that don't allow browser requests (AdGuard, OpenDNS, NextDNS) can't be used here. The setting is remembered in this browser and can be passed in the link as ?filter=<url>.
